# 자바 개요

## JDK

JDK는 자바 프로그램을 개발하기 위한 도구 모음을 말한다.

```
JDK
 ├─ JRE
 │   ├─ JVM
 │   │   ├─ 클래스 로더
 │   │   ├─ 실행 엔진
 │   │   │   ├─ 인터프리터
 │   │   │   └─ JIT
 │   └─ 표준 라이브러리
 └─ 개발 도구
     ├─ javac
     ├─ java (자바 프로그램을 실행할 때 쓰는 명령어)
     ├─ javadoc (자바 코드에 적은 주석을 바탕으로 문서(html) 를 만들어 주는 도구)
     └─ jar (여러 .class 파일, 리소스 파일 등을 하나의 묶음 파일(.jar) 으로 압축/패키징하는 도구)
```

## 실행 흐름

1. `javac` 컴파일러가 소스 코드(.java)를 바이트코드(.class)로 컴파일한다.
2. 프로그램을 실행하면 `JVM`이 시작되고, 클래스 로더가 `Main` 클래스를 먼저 로드(JVM에 전달)한다.
3. `JVM`은 `Main`의 바이트코드를 읽어 실행하며, 실행 흐름에 따라 필요한 다른 클래스들도 그때그때 로드한다.
4. 이때 `JVM`은 바이트코드를 해석하여 실행(CPU가 수행할 수 있도록 처리)하고, 자주 실행되는 부분은 `JIT` 컴파일러가 기계어로 변환해 캐시해 둔다.
5. 이후 같은 코드가 반복 실행되면, `JVM`은 다시 해석하지 않고 이미 변환된 기계어를 사용하여 더 빠르게 실행한다.
