# 연속된 부분 수열의 합

> 문제 설명

비내림차순으로 정렬된 수열이 주어질 때, 다음 조건을 만족하는 부분 수열을 찾으려고 합니다.

기존 수열에서 임의의 두 인덱스의 원소와 그 사이의 원소를 모두 포함하는 부분 수열이어야 합니다.
부분 수열의 합은 k입니다.<br>
합이 k인 부분 수열이 여러 개인 경우 길이가 짧은 수열을 찾습니다.<br>
길이가 짧은 수열이 여러 개인 경우 앞쪽(시작 인덱스가 작은)에 나오는 수열을 찾습니다.<br>
수열을 나타내는 정수 배열 sequence와 부분 수열의 합을 나타내는 정수 k가 매개변수로 주어질 때,<br>
위 조건을 만족하는 부분 수열의 시작 인덱스와 마지막 인덱스를 배열에 담아 return 하는 solution 함수를 완성해주세요.<br>
이때 수열의 인덱스는 0부터 시작합니다.

> 제한사항

5 ≤ sequence의 길이 ≤ 1,000,000<br>
1 ≤ sequence의 원소 ≤ 1,000<br>
sequence는 비내림차순으로 정렬되어 있습니다.

5 ≤ k ≤ 1,000,000,000<br>
k는 항상 sequence의 부분 수열로 만들 수 있는 값입니다.

> 입출력 예

sequence / k / result<br>
[1, 2, 3, 4, 5]	/ 7	/ [2, 3]<br>
[1, 1, 1, 2, 3, 4, 5]	/ 5	/ [6, 6]<br>
[2, 2, 2, 2, 2]	/ 6	/ [0, 2]<br>

> 입출력 예 설명

#### 입출력 예 #1

[1, 2, 3, 4, 5]에서 합이 7인 연속된 부분 수열은 [3, 4]뿐이므로 해당 수열의 시작 인덱스인 2와 마지막 인덱스 3을 배열에 담아 [2, 3]을 반환합니다.

#### 입출력 예 #2

[1, 1, 1, 2, 3, 4, 5]에서 합이 5인 연속된 부분 수열은 [1, 1, 1, 2], [2, 3], [5]가 있습니다.<br>
이 중 [5]의 길이가 제일 짧으므로 해당 수열의 시작 인덱스와 마지막 인덱스를 담은 [6, 6]을 반환합니다.

#### 입출력 예 #3

[2, 2, 2, 2, 2]에서 합이 6인 연속된 부분 수열은 [2, 2, 2]로 3가지 경우가 있는데,<br>
길이가 짧은 수열이 여러 개인 경우 앞쪽에 나온 수열을 찾으므로 [0, 2]를 반환합니다.

> 풀이

### 1. 투 포인터 + 슬라이딩 윈도우

#### 정답 코드

```java
import java.util.*;

// 1. 투 포인터 + 슬라이딩 윈도우
class Solution {
  public int[] solution(int[] sequence, int k) {
    int[] answer = {};

    int l = sequence.length;

    int l_answer = Integer.MAX_VALUE;
    int left_answer = Integer.MAX_VALUE;
    int right_answer = Integer.MAX_VALUE;

    int cur_sum = sequence[0];
    int cur_l = 1;
    int left = 0;
    int right = 0;

    while (left != l - 1 || left != right) {
      if (cur_sum == k && cur_l < l_answer) {
        left_answer = left;
        right_answer = right;
        l_answer = cur_l;
      }

      if (cur_sum < k && right < l - 1) {
        right++;
        cur_sum = cur_sum + sequence[right];
        cur_l++;
      } else {
        cur_sum = cur_sum - sequence[left];
        left++;
        cur_l--;
      }
    }
    if (cur_sum == k && cur_l < l_answer) {
      left_answer = left;
      right_answer = right;
      l_answer = cur_l;
    }

    answer = new int[] { left_answer, right_answer };

    return answer;
  }
}
```

### 2. 누적합 + 이분 탐색

```java
import java.util.*;

// 2. 누적합 + 이분 탐색
class Solution {
  public int[] solution(int[] sequence, int k) {
    int[] answer = {};

    int l = sequence.length;
    int[] prefix_sum = new int[l + 1];
    prefix_sum[0] = 0;

    // 누적합 수열 생성
    int sum = 0;
    for (int i = 0; i < l; i++) {
      sum = sum + sequence[i];
      prefix_sum[i + 1] = sum;
    }

    // 탐색
    int l_answer = Integer.MAX_VALUE;
    int left_answer = 0;
    int right_answer = 0;

    int pivot_idx = 0;
    int target_value = 0;
    while (pivot_idx != l) {
      target_value = prefix_sum[pivot_idx] + k;

      // 이분 탐색
      int left = pivot_idx + 1;
      int right = l;
      int middle = (left + right) / 2;

      // 이분 탐색에서 left, right 또한 마지막까지 항상 탐색 대상이 된다.
      // 따라서 left == right 인 경우에도 한 번 더 탐색을 진행해야 한다.
      while (left <= right) {
        middle = (left + right) / 2;

        int cur_found = prefix_sum[middle];
        int cur_l = middle - pivot_idx;
        if (cur_found == target_value && cur_l < l_answer) {
          left_answer = pivot_idx;
          right_answer = middle - 1;
          l_answer = cur_l;
        }

        if (cur_found > target_value) {
          right = middle - 1;
        } else {
          left = middle + 1;
        }

      }
      pivot_idx++;
    }

    answer = new int[] { left_answer, right_answer };

    return answer;
  }
}
```
